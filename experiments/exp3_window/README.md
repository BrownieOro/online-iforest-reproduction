# Phân tích bổ sung - Kích thước cửa sổ

Đề xuất của nhóm, không phải thí nghiệm tái tạo nguyên xi: thay ω, giữ các tham số khác cố định, đo chất lượng phát hiện, thời gian và khả năng thích nghi. Có thể thử 256, 512, 2048, 8192 sau khi chốt protocol và tài nguyên.

Chưa có code hoặc kết quả. Khi triển khai, thêm `run.py`, cấu hình, hướng dẫn chạy, seed và W&B URL. Dùng thuật toán trong `model/`. Không kết luận trước rằng cửa sổ nào tốt nhất.
