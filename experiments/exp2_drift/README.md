# Thí nghiệm chính 2 - Dữ liệu thay đổi theo thời gian

Đề xuất: dùng INSECTS theo Mục 5.1, đánh giá AUC theo thời gian và đối chiếu Hình 7. Phân biệt cửa sổ học với cửa sổ đánh giá, giữ thứ tự thời gian.

Chưa có code hoặc kết quả. Khi triển khai, thêm `run.py`, cấu hình, hướng dẫn chạy, seed và W&B URL. Dùng thuật toán trong `model/`.
