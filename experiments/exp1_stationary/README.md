# Thí nghiệm chính 1 - Dữ liệu ổn định

Đề xuất: so chất lượng phát hiện và thời gian trên Annthyroid, Mammography, Satellite và Shuttle, đối chiếu Bảng 4 của bài. Nhóm cần chốt bộ dữ liệu và các phương pháp so sánh sau chạy thử.

Chưa có code hoặc kết quả. Khi triển khai, thêm `run.py`, cấu hình, hướng dẫn chạy, seed và W&B URL. Dùng thuật toán trong `model/`, không tạo bản riêng.
