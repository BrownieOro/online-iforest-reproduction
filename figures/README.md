# Biểu đồ do nhóm tạo

Hai biểu đồ thí nghiệm dữ liệu ổn định được tạo từ bảng tổng hợp các lần chạy
bằng [`experiments/exp1_stationary/plot_summary.py`](../experiments/exp1_stationary/plot_summary.py):

- `stationary-auc.png` — so sánh ROC-AUC.
- `stationary-time.png` — so sánh thời gian xử lý.

Đường dẫn W&B của các lần chạy dùng để tạo biểu đồ chưa có vì chưa tải kết quả
lên W&B. Hình trong `papers/figures/` là hình trích từ bài báo để đọc tài liệu,
không phải hình do nhóm tạo để đưa vào slide.
