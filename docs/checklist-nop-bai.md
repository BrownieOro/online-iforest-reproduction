# Danh sách kiểm tra trước khi nộp

Tóm tắt từ [yêu cầu đồ án](yeu-cau-do-an.md). Khi có cập nhật, ưu tiên Moodle và hướng dẫn giảng viên.

## Slide - 45%, hạn 23:59 ngày 21/11/2026

- [ ] Một file `ID.pptx`, ID là số nguyên ID nhóm đã đăng ký.
- [ ] 20-40 slide, tính cả phụ lục; file dưới 20 MB.
- [ ] Gộp đọc hiểu và tái tạo thực nghiệm.
- [ ] Mọi slide có speaker notes, mỗi slide tối đa 500 từ.
- [ ] Slide và notes đủ để chấm độc lập vì mốc này không thuyết trình miệng.
- [ ] Bối cảnh có ví dụ của nhóm; phân tích ít nhất hai phương pháp tiền nhiệm, hạn chế và hệ quả.
- [ ] Nêu đóng góp và tính mới so với tiền nhiệm.
- [ ] Đủ ký hiệu/bài toán, pipeline, từng thành phần/công thức, tính chất lý thuyết và độ phức tạp.
- [ ] Nêu phạm vi tái tạo và lý do; phạm vi cốt lõi có ít nhất hai thí nghiệm quan trọng kèm phân tích bổ sung do nhóm tự thiết kế.
- [ ] Bảng kết quả paper/nhóm, độ lệch tương đối và giải thích sai lệch.
- [ ] Nếu có code tác giả: đã chạy, so sánh đầu ra và chỉ rõ khác biệt quy trình.
- [ ] Mọi số liệu của nhóm có link W&B run.
- [ ] Hình do nhóm vẽ/tái tạo, không dán hình từ paper; không nhồi mã nguồn thô.
- [ ] Trích dẫn IEEE đánh số ở cuối slide sử dụng nguồn; không có slide references riêng.
- [ ] Tải file PPTX lên Moodle và nộp link repo công khai thành mục riêng.

## Repo và thực nghiệm

- [ ] Repo công khai, có lịch sử làm việc và commit thường xuyên.
- [ ] Tự triển khai; không nộp code tác giả như sản phẩm nhóm.
- [ ] Python ≥ 3.9; các công cụ ngoài bộ quy định được giải thích trong README.
- [ ] Hàm quan trọng có docstring về mục đích, tham số, giá trị trả về.
- [ ] README hướng dẫn cài và chạy lại toàn bộ, có code chuẩn bị dữ liệu.
- [ ] Seed và phiên bản thư viện được ghi lại; các lần chạy là thật và đã hoàn thành.
- [ ] W&B project công khai, có cấu hình, metric và biểu đồ.
- [ ] Hai phần tái tạo và kiểm chứng dùng cùng W&B project, có tag phân biệt.
- [ ] README có bảng thí nghiệm → notebook/script → W&B run → kết quả tóm tắt.

## Poster - 50%, hạn kiểm tra trên Moodle

- [ ] Một file PPTX, đúng một slide A2 dọc.
- [ ] Gộp phê bình lý thuyết và thực nghiệm kiểm chứng, nối lập luận với bằng chứng.
- [ ] Ít nhất ba điểm mạnh có lập luận/bằng chứng, hai hạn chế lý thuyết đủ cụ thể để kiểm tra, hai hướng tương lai từ phê bình.
- [ ] Thí nghiệm chỉ rõ hạn chế nào → kiểm tra thế nào → đo gì → kết quả nói gì.
- [ ] Số liệu có W&B run; repo và khả năng tái lập đầy đủ.
- [ ] Mọi thành viên có thể giải thích toàn bộ sản phẩm tại symposium.
