# Dữ liệu

Chưa tải dữ liệu. Nguồn tham khảo: [dữ liệu repo tác giả](https://github.com/ineveLoppiliF/Online-Isolation-Forest/tree/main/datasets).

Khi triển khai, thêm code tải/chuẩn bị, ghi nguồn, phiên bản, checksum, cột đặc trưng và nhãn, cách lọc lớp và xử lý thứ tự.

- `raw/`: dữ liệu tải về, Git bỏ qua.
- `processed/`: dữ liệu đã xử lý, Git bỏ qua.
- INSECTS: giữ thứ tự thời gian; đối chiếu các lớp đã chọn ở Mục 5.1 của bài.
- Dữ liệu dừng: chốt cùng thứ tự xáo trộn theo seed cho mọi phương pháp so sánh.
