# Kết quả của nhóm

Chưa có kết quả. Chỉ thêm số liệu do nhóm đã chạy thật, kèm dataset, model, seed, cấu hình, metric, thời gian, phiên bản code và W&B URL.

Không chép số liệu paper vào bảng kết quả nhóm. Nếu thêm bảng đối chiếu, đặt cột nguồn rõ ràng. Đầu ra thô lớn để trong `raw/` hoặc nơi lưu được ghi trong README; `raw/` được Git bỏ qua.
