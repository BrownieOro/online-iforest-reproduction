# Kết quả của nhóm

Thí nghiệm dữ liệu ổn định đã chạy đủ 30 seed trên Annthyroid và Mammography.
Xem [bảng tổng hợp và nhận xét](stationary.md), script tại
[`experiments/exp1_stationary/`](../experiments/exp1_stationary/) và số liệu
trong [`stationary-summary.csv`](stationary-summary.csv). Các đường dẫn W&B
trực tuyến chưa có; cần cấu hình project và tài khoản rồi tải các lần chạy cục
bộ lên.

Không chép số liệu bài báo vào bảng kết quả của nhóm. Nếu thêm bảng đối chiếu,
ghi rõ nguồn từng cột. Lưu kết quả thô trong `raw/` hoặc tại vị trí được nêu
trong hướng dẫn thí nghiệm; Git đang bỏ qua thư mục `raw/`.
